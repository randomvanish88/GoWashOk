Si desplegaste en Vercel, es aún más fácil:

```
En la PC:
1. Doble clic en: deploy-vercel.bat
2. Sigue las instrucciones

```

```
3. ¡Listo!
```

**Ventaja:** No necesitas que la PC esté encendida! 🎉

## ⚠️ SOLUCIÓN DE PROBLEMAS

### ❌ "No puedo acceder desde el celular"

```
Checklist:
□ ¿Estás en la MISMA WiFi que la PC?
□ ¿Usaste la IP correcta? (ej: 192.168.1.100)
□ ¿Ejecutaste con --host? (npm run dev:mobile)
□ ¿El firewall está bloqueando? (prueba desactivarlo)
□ ¿Escribiste :5173 al final? (ej: 192.168.1.100:5173)

Prueba:
1. Desde la PC: ping 192.168.1.100
2. Desde la PC abre: http://192.168.1.100:5173
   Si funciona, el problema es la red entre PC y celular
```

### ❌ "No aparece opción de instalar"

```
Android:
- Solo funciona en Chrome o Edge (no Firefox)
- Debe ser HTTPS o localhost (para red local está ok)
- Verifica que manifest.json esté cargando

iOS:
- Solo funciona en Safari (no Chrome)
- No funciona en modo privado
- Debe tener manifest.json válido
```

### ❌ "Se instaló pero no funciona offline"

```
Solución:
1. El Service Worker tarda en cargar la primera vez
2. Abre la app 2-3 veces para que cachee todo
3. Luego desactiva WiFi y prueba
4. La primera pantalla (login) funcionará offline
5. Google Sheets no funciona offline (requiere internet)
```

## 🎓 TIPS PRO

### 1. URL Corta para compartir
```
Si instalas en Vercel, obtienes:
https://gowash-xyz123.vercel.app

Puedes usar un acortador:
→ bit.ly/gowash-app
→ tiny.cc/gowash

O configurar dominio propio:
→ app.gowash.com
```

### 2. Código QR para instalación
```
1. Genera QR de tu URL (https://qr-code-generator.com)
2. Imprime o guarda el QR
3. Los empleados escanean el QR
4. Se abre la app en el celular
5. Instalan con 2 toques

Útil para capacitación!
```

### 3. Múltiples dispositivos
```
Todos usan la misma URL:
- Celular del gerente
- Celular del empleado 1
- Celular del empleado 2
- Tablet en recepción

Todos comparten datos (con Google Sheets sincronizado)
```

### 4. Actualización automática
```
PWA se actualiza sola:
1. Subes nueva versión a Vercel
2. La próxima vez que abran la app
3. Se actualiza automáticamente
4. Sin reinstalar!

Los usuarios siempre tienen la última versión 🎉
```
