Para sincronizar datos con Google Sheets:

  5. Ingresa el ID de tu hoja

🆘 SI ALGO SALE MAL
══════════════════════════════════════════════════════════════

Error: "vercel not found"
  → npm install -g vercel

Error: "Not authenticated"  
  → vercel.cmd login

Error: "PowerShell scripts disabled"
  → Usa CMD en lugar de PowerShell
  → O ejecuta: vercel.cmd (con .cmd)

El comando no hace nada:
  → Presiona Ctrl+C
  → Abre nueva terminal CMD
  → Ejecuta de nuevo

Build fallido:
  → npm run build
  → Revisa errores en consola
